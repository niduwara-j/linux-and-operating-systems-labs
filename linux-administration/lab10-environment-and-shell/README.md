# Environment Variables and Shell Scripts

This lab demonstrates basic Linux shell scripting concepts:

- Environment variables
- User-defined variables
- Script execution permissions
- Basic command execution
- Displaying system information

## Files

### usrinfo.sh
Demonstrates variable declaration and formatted output.

### welcome-script.sh
Displays a welcome message and current system date/time.

## Skills Demonstrated

- Bash scripting
- Variable handling
- Command substitution
- Linux command-line usage
- Script execution permissions
